The Loop

런타임이 쉬지 않고 도는 하나의 순환

기존 생성형 AI가 '프롬프트 → 응답'이라면, Particle AI는 사건을 관찰하고 스스로 결정해 인터페이스를 계속 재구성합니다.

01

관찰

클릭·체류·탭 전환·유휴·되돌리기 같은 행동과, 통신의 형태(호스트·상태·지연 — 내용은 절대 아님)를 계속 감지합니다. 빌드 실패나 HTTP 500은 그중 한 케이스일 뿐입니다.

02

판단

행동에서 의도(탐색·집중·막힘·전환·복귀)를 항상 추론하고, 지금 상황에 의미 있는 변화인지 값싸게 먼저 가려냅니다.

03

결정

무엇을 보여주고 어떤 능력을 실행할지 구조화된 결정을 내립니다.

04

재구성

승인된 부품만 조합해 화면을 변형합니다 — 언제든 되돌릴 수 있게.

Why it's different

똑똑하게 반응하고, 안전하게 실행합니다

Autonomous

자율적

요청도, 에러도 필요 없습니다. 자리를 비웠다 돌아오면 요약이, 같은 행동을 반복하면 관련 컨텍스트가, 두 곳을 오가면 고정 카드가 먼저 기다립니다.

  • 행동·통신 형태 → 의도 → 자동 변형
  • 무관한 이벤트는 무시
  • 같은 변경을 두 번 닫으면 다시 제안하지 않음
Safe

안전함

모델이 코드를 만들지 않고, 검증된 UI 데이터만 생성합니다.

  • 모든 변형 되돌리기 가능
  • 위험 작업은 사람 승인 필수
  • 모든 결정 감사 가능
  • 형태만 감지 — 내용은 절대 수집하지 않음
Independent

독립적

특정 모델에 묶이지 않습니다.

  • API 키 없이도 작동
  • 어떤 LLM으로도 교체
  • 로컬 모델 지원
How to explain it

"AI를 쓰는 게 아니라,
AI가 소프트웨어가 됩니다."

인터페이스는 AI의 몸, 당신의 행동은 AI의 감각입니다. 당신이 바뀌면, 몸이 바뀝니다.

개발자에게
"인시던트·빌드 실패마다 필요한 화면이 자동으로 준비됩니다."
경영진에게
"직원이 도구를 찾는 게 아니라, 도구가 상황에 맞춰 스스로 준비됩니다."
투자자에게
"응답하는 AI가 아니라, 스스로를 재구성하는 AI 런타임."
