# Roadmap

## Now (V1 — the proof)

Observe meaningful events → autonomously reshape a structured interface → stable,
explainable, reversible, provider-independent, permission-controlled. Delivered across
Phases 0–8 (see `STATUS.md`).

## Deferred research (extension points designed, not implemented)

- Contextual generative UI (richer, learned layouts)
- Long-term behavioral learning & pattern compression ("software DNA")
- Capability mutation / self-growing workflows (currently: *suggest* reusable patterns only)
- Multi-device digital matter, spatial interfaces
- Local-first intelligence, distributed AI cells, swarm intelligence
- Automatic workspace synthesis, user-specific morphology, shared org memory

Each has a designed seam (provider interface, capability registry, memory pattern
detector, event source adapters) so it can be added without rewriting the core runtime.
