# Branding

## Names

- **Product name:** **Particle AI**
- **Runtime codename:** **Morphogen** — the engine that continuously reshapes the interface
  around the situation (from *morphogenesis*, the biological process by which form emerges).
- **Paper-style title:** *Situated Adaptive Interfaces — A Runtime for Self-Restructuring UIs*.

## Tagline

> The AI becomes the software.

Alternates: "Software that reshapes itself around you." · "An interface with a nervous system."

## Positioning (one paragraph)

Particle AI is an adaptive computing runtime. Instead of a fixed application the user must
learn and operate, the interface is the AI's body: it observes meaningful events, judges
whether they matter, decides, and restructures itself — stably, explainably, reversibly, and
under human permission. It is not a chatbot and not a dashboard with an AI panel; the runtime
*is* the product.

## Voice

Technical, calm, precise. We describe capabilities, not hype. Prefer "the runtime decides"
over "magic". Never claim autonomy we don't have — every autonomous action is bounded by the
permission engine and is reversible.

## Visual identity

- **Mark:** a particle — a bright core with an orbiting satellite, suggesting a small system
  that reorganizes. See `apps/web/app/icon.svg`.
- **Primary color:** Material 3 purple `#6750A4` (`--primary-600`); lighter `#D0BCFF` in dark mode.
- **Type:** Roboto / system sans. Monospace for code, logs, and identifiers.
- **Motion:** communicates *morphing* (a transition of state), never decoration.

## Do / Don't

- **Do** show the runtime noticing and reshaping on its own; show the "why" (Inspector).
- **Do** keep the demo self-contained (mock brain, no key required).
- **Don't** present it as a chat product or a static dashboard.
- **Don't** imply unbounded autonomy — always surface permission, approval, and undo.
